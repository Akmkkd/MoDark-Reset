# 🕷️ Mo.dark Reset v7.0

## Guest Reset Tool for PUBG Mobile (com.tencent.ig)

### الوصف
تطبيق Android احترافي يعيد تعيين بيانات الضيف (Guest) لتطبيق PUBG Mobile، مع واجهة مستخدم عصرية بتصميم Cyberpunk Dark Neon.

### الميزات
- ✅ إعادة تعيين كاملة لبيانات الضيف
- ⛔ قتل التطبيق فقط
- 🌐 حظر خوادم Tencent (cloud.vmp.onezapp.com)
- 📋 سجل عمليات مفصل مع عداد
- 🎨 واجهة مستخدم فاخرة بتأثيرات نيون
- 🔒 يتطلب صلاحيات الجذر (Root)

### التثبيت
1. تحميل ملف APK من [Releases](../../releases)
2. تثبيت التطبيق على جهاز Android
3. منح صلاحيات الجذر (Root)
4. تشغيل التطبيق والاستمتاع
